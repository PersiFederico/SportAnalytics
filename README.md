*Project Summary*
This personal project is designed to develop and apply ETL pipeline concepts by extracting personal training data from Strava and Garmin, 
transforming and visualizing the data, identifying performance patterns and trends, and generating training recommendations tailored to specific 
goals and race objectives.

*Architecture*:
-  Data Extraction & Processing: Training data is extracted from Strava and Garmin and processed through a Python-based ETL pipeline.
-  Data Storage: Processed data is stored in a Supabase PostgreSQL database.
-  Analysis & Visualization: Python is used to analyze training metrics, identify performance trends, and generate visualizations.
-  Recommendations Engine: Insights derived from the data are leveraged to provide personalized recommendations for training goals and race preparation.
